# Satin Road

Satin Road is an e-commerce marketplace where users can create listings, manage their inventory and buy products from other users.

The application was developed as a group project using .NET 10, Linq2DB, React, Bun and swagger-typescript-api.

## Features

- Browse available product listings
- Create product listings
- Manage product inventory
- Buy products from other users
- View order history
- Manage product categories
- Product images
- Special business rules such as vendor featuring, purchase discounts and the FBI event# satin_road

## Tech Stack

### Backend
- .NET 10
- Linq2DB
- OpenAPI / Swagger

### Frontend
- React
- Bun
- TypeScript
- swagger-typescript-api

### Database
- Microsoft SQL Server

## Testing Methodology

We used a Test Last approach. We implemented the functionality first and then identified important business logic that should be tested.

We focused on validation and business rules rather than aiming for 100% code coverage.

## Sustainability

We used Lighthouse to evaluate the application and considered performance, accessibility and sustainability when optimizing the frontend.

We focused on keeping the application simple, avoiding unnecessary resources and optimizing the user experience.
